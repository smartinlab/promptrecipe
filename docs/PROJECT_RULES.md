## Deployment Model

**Embedded pure-Python library.** No service, no daemon, no infrastructure, no compiled extension. Runs in the consumer's process. Distributed as a pure-Python wheel that builds once and installs everywhere.

## Prohibited

| Prohibited | Reason |
|---|---|
| **Any template engine as the fragment mechanism** | Violates E1 — fragment content must never be rendered. The product's core security guarantee |
| **Evaluating fragment content anywhere** | ADR-003, amendment 8. Optimizer-written text must never execute |
| **`eval`, `exec`, `compile`, or `__import__` anywhere in the library** | Same guarantee, stated in Python terms. This is the single most important prohibition in this file |
| **Re-parsing a substituted value** | ADR-006 |
| **Output ordering from `set` iteration, `os.listdir` order, or locale-sensitive comparison** | TRD §4 determinism. Sort explicitly; never rely on insertion or filesystem order for output |
| **`datetime.now()` or environment reads in the assembly path** | TRD §4 — wall-clock and environment leakage |
| **Async framework or logging backend as a runtime dependency** | A library on an agent's request path must impose neither on its host |
| **Adding a second runtime dependency without justification** | One runtime dependency is a deliberate property, not an accident |
| **Version ranges without documented justification** | Reproducible builds |
| **Partial output on any failure path** | TRD §7. No warn-and-continue exists in the assembly path |

## Determinism Rules (TRD §4 — not retrofittable)

1. Every collection whose order can reach output is a `list` or a sorted iteration. **Never** a `set`, never unsorted `dict` iteration for output ordering.
2. `os.listdir` / `Path.iterdir` results are **sorted explicitly** before use.
3. No `datetime`, no `time`, no `os.environ` in the assembly path.
4. No `str.lower()` / `str.upper()` for comparison logic — locale-sensitive casing is a determinism hazard.
5. Digests are computed over **canonically ordered** fields; timestamps are excluded from every digest.

## Security & Compliance

- **Runtime licensing:** the single runtime dependency is permissive (CC0-1.0 / Apache-2.0). Distributable under a permissive license. `[UNVERIFIED per-manifest — task 0.4]`
- **Dev licensing:** `hypothesis` is MPL-2.0 (weak copyleft). Dev-only, never in the wheel. Verify the boundary holds at packaging time.
- **Dependency audit:** **required before first code** — task 0.3. Not performed at Gate 6.
- **Trust boundary:** recipe conditions are evaluated by a total, bounded language; **fragment content is never evaluated**; value substitution is literal, last, and never re-parsed.
- **Known non-mitigable risk:** value substitution is the prompt-injection surface. Values cannot alter structure, and every binding is recorded in provenance so injection is forensically visible — but the library cannot validate the semantics of caller-supplied text.
